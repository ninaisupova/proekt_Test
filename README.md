# ЧУДЕСА — генератор контента

Веб-приложение для быстрого создания контента от лица эксперта: познавательный пост на день и интерактивный мини-тест для вовлечения аудитории.

## Назначение

Проект помогает блогерам, экспертам и SMM-специалистам за минуту получить готовую идею публикации: текст поста в экспертной нише и квиз из 5 вопросов с проверкой ответов. Всё работает прямо в браузере — без сервера и установки.

## Основные функции

- **Выбор эксперта** — фотограф, психолог, тренер, нутрициолог, стилист, логопед, финансовый советник, карьерный коуч
- **Генерация поста** — познавательный и вовлекающий текст на один день с заголовком, телом и призывом к действию
- **Мини-тест** — 5 вопросов, у каждого 3 варианта ответа
- **Мгновенная проверка** — после выбора варианта показывается правильный ответ и ведётся счёт верных ответов
- **Тёмный интерфейс** — чёрно-серебристое оформление с анимациями

## Технологии

| Технология | Назначение |
|---|---|
| **HTML5** | Структура страницы |
| **CSS3** | Стили, адаптивная вёрстка, анимации |
| **JavaScript (vanilla)** | Логика выбора эксперта, генерации контента и квиза |
| **Google Fonts** | Шрифты Cinzel и Manrope |

Стек намеренно простой: один файл `index.html`, без фреймворков и сборки.

## Использование

1. Выбери эксперта на панели.
2. Нажми **«Сгенерировать»**.
3. Прочитай пост и пройди мини-тест — правильный ответ откроется сразу после выбора варианта.
